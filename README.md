# Student Management System

A simple student management program made with basic Python OOP.

## Features
- View all students
- Enroll a student
- Drop a student
- Shows error for wrong student ID, already enrolled, or not enrolled

## Classes
- **StudentDatabase**: keeps all students in `student_list`
- **Student**: has id, name, department and enroll status (all private)

## How to run
```
python student_management.py
```

Then choose an option from the menu:
```
1. View All Students
2. Enroll Student
3. Drop Student
4. Exit
```
